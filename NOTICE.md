The [MIT licence](LICENSE) covers the source code and documentation authored in
this repository. It does **not** relicense third-party data or model artefacts,
which retain their own terms:

| Source | Terms |
|---|---|
| OpenAQ station observations, and the Indian providers behind them (CPCB, state pollution control boards) | See the provider's terms; redistribution terms for bulk historical archives are not independently verified here |
| Copernicus CAMS and ERA5 | Copernicus licence; attribution required |
| NOAA GFS | U.S. Government work, public domain |
| SILAM (Finnish Meteorological Institute) | CC BY 4.0 |
| Microsoft Aurora model weights | See the Aurora repository's licence |

Derived tables in this repository inherit the terms of their upstream sources.

This repository is research output, not a data redistribution service. If you
intend to reuse any dataset here, go to the upstream source and its terms
rather than relying on this copy.
